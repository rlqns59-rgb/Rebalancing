☁ 여러 기기 동기화

본인 소유의 Firebase 프로젝트에 연결하면, PC·휴대폰 등 여러 기기에서 로그인해 같은 데이터를 실시간으로 봅니다. 연결하지 않아도 앱은 지금처럼 이 브라우저의 localStorage에 정상 저장됩니다 — 동기화는 선택 사항입니다.

1 Firebase 프로젝트 설정 붙여넣기

Firebase 콘솔 → 프로젝트 설정 → 일반 → '내 앱'에서 웹 앱(</>)을 추가하면 나오는 firebaseConfig 객체를 그대로 복사해 붙여넣으세요. (아래 3번에 계정 만드는 법이 있습니다.)

2 계정 로그인 이 기기와 다른 기기에서 같은 이메일로 로그인하면 데이터가 동기화됩니다
로그인됨:
3 Firebase 프로젝트가 처음이라면
  1. console.firebase.google.com → 프로젝트 추가 (무료 Spark 요금제로 충분)
  2. 왼쪽 메뉴 Firestore Database → 데이터베이스 만들기 → 프로덕션 모드 → 리전은 asia-northeast3(서울) 추천
  3. 왼쪽 메뉴 Authentication → Sign-in method → 이메일/비밀번호 사용 설정
  4. Firestore의 규칙(Rules) 탭에 아래 규칙을 붙여넣고 게시 — 본인 계정으로 로그인한 사람만 자기 데이터를 읽고 쓸 수 있게 제한합니다
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/data/{docId} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
  1. 프로젝트 설정(⚙) → 일반 → 내 앱 → 웹 앱 추가(</> 아이콘) → 앱 닉네임 아무거나 입력 → 나오는 firebaseConfig를 위 1번에 붙여넣기
firebaseConfig 안의 값들은 비밀키가 아니라 '이 웹사이트가 어느 프로젝트를 쓰는지' 알려주는 공개 정보입니다. 실제 보안은 위 Firestore 규칙(본인 uid만 허용)이 담당하므로, 이 코드가 공개 GitHub 저장소에 올라가도 규칙을 그대로 쓰면 안전합니다.

⚙ 시세 API 설정 Twelve Data 무료 키

해외 상장 티커(SPY, O, GLD 등)의 현재가·52주 최고가를 자동으로 불러옵니다. 국내 종목(6자리 코드)은 무료 API가 지원하지 않아 계속 수동 입력합니다. 키는 이 브라우저의 localStorage에만 저장되고, JSON 백업 파일에는 포함되지 않습니다.

키 발급 방법 (1분, 무료)
  1. twelvedata.com 접속 → 우측 상단 Sign up으로 이메일 가입 (무료 플랜 선택, 카드 등록 불필요)
  2. 로그인하면 나오는 Dashboard 첫 화면에 API Key가 바로 보입니다 (32자리 문자열)
  3. 그 값을 복사해서 위 입력칸에 붙여넣고 저장 후 테스트를 누르면 정상 연결 여부를 바로 확인합니다
무료 플랜은 분당 8개 종목까지만 조회됩니다(일 800회). 종목이 8개를 넘으면 앱이 자동으로 8개씩 나눠서 순차 조회하며, 그룹 사이마다 약 1분씩 기다립니다 — 예를 들어 관심주 12종목이면 시세 갱신에 1분 정도 걸립니다. 버튼 문구에 진행 상황(예: 대기 중 2/2)이 표시됩니다.

1 대구분(4단계) 이란

모든 종목을 현금자산 / 안전자산 / 배당자산 / 투자자산 4단계 중 하나로 묶어서 관리합니다. 개별 종목보다 대구분 비중이 먼저입니다. 홈과 보유종목 탭에서 대구분 비중을 먼저 보고, 그 다음 종목 비중을 봅니다.

  • 1단계 현금자산 — 파킹통장, CMA, 초단기채. 리밸런싱 실탄이자 배당금이 모이는 곳.
  • 2단계 안전자산 — 국채·회사채·금 등 주식과 다르게 움직이는 자산.
  • 3단계 배당자산 — 배당·분배금이 꾸준히 나오는 리츠, 고배당 ETF.
  • 4단계 투자자산 — 지수 ETF, 성장주 등 수익률을 끌어올리는 자산.

2 시세 자동 갱신 — 📡 시세 갱신 (해외)

관심주·보유종목 탭 상단의 📡 시세 갱신 버튼을 누르면 해외 상장 티커(SPY, O, GLD 등)의 현재가와 52주 최고가를 Twelve Data 무료 API로 불러옵니다. 헤더의 ⚙ 시세 API 설정에서 먼저 키를 등록해야 하며, 발급 방법은 그 팝업 안에 그대로 안내되어 있습니다. 국내 6자리 코드 종목은 무료 API가 지원하지 않아 계속 직접 입력해야 합니다. 키는 이 브라우저에만 저장되고 JSON 백업에는 포함되지 않습니다.

무료 플랜은 분당 8종목까지만 조회할 수 있습니다. 종목이 8개를 넘으면 앱이 자동으로 8개씩 나눠서 순차 조회하고, 그룹 사이마다 약 1분씩 기다립니다(버튼에 "대기 중 2/2"처럼 진행 상황이 표시됩니다). "API credits" 초과 오류가 뜨면 정상 동작 중인 것이니 잠시 후 다시 눌러보세요.

3 관심주 탭 — 살 종목을 미리 재어두는 곳

아직 사지 않았지만 지켜보는 종목을 등록합니다. 여기서 입력하는 값의 의미는 이렇습니다.

입력칸무엇을 넣나
대구분이 종목을 어떤 목적으로 사는지(안전/배당/투자 등). 상단 칩으로 대구분별 필터링됩니다.
현재가지금 주가. 증권사 앱에서 보고 수동 입력합니다(자동 시세 연동 없음).
전고점52주 최고가 또는 내가 기준으로 삼는 고점. 낙폭(MDD) 계산의 기준값이라 반드시 넣어야 시그널이 뜹니다.
목표가여기까지 오르면 판다고 정한 가격. 상승여력 = (목표가−현재가)÷현재가.
관심 사유왜 이 종목을 보는지. 나중에 흔들릴 때 다시 읽는 근거입니다.

표의 헤더를 클릭하면 정렬됩니다(한 번 더 누르면 역순). 낙폭 기준으로 정렬하면 가장 많이 빠진 종목이 위로 옵니다. 체크박스로 여러 개 고른 뒤 [비교하기]를 누르면 나란히 비교표가 나옵니다.

4 낙폭(MDD) 매수 · 회복 실현 전략

낙폭(MDD) = (현재가 − 전고점) ÷ 전고점 × 100
진입강도 R = |현재 낙폭| ÷ 기준 낙폭 · R이 1.00 이상이면 매수 신호입니다.
기준 낙폭은 자산마다 다릅니다. [예산배분] 탭 STEP 1에서 대구분별 기본값(안전 −12% / 배당 −10% / 투자 −20%)을 정하고, 개별 종목만 다르게 하려면 [관심주] 추가·수정 폼의 기준 MDD에 직접 넣습니다(예: 테슬라 −50%, 비트코인 −48%). 표의 R 버튼을 누르면 현재가·전고점·기준 낙폭이 각각 언제 기준인지와 계산식이 팝업으로 뜹니다.
  • 매수구간 R ≥ 1.00 — 기준 낙폭에 도달, 담을 구간
  • 관찰 R ≥ 0.75 — 기준의 3/4까지 내려온 상태, 곧 도달
  • 관망 아직 충분히 빠지지 않음
  • 실현 검토 (보유종목) 현재가가 전고점 회복 기준에 도달 — 정리 검토

홈 상단 배너에 지금 매수구간에 들어온 종목 수와 실현 검토 종목 수가 요약됩니다. 전고점·현재가를 입력해두지 않으면 판정되지 않으니, 가격은 주기적으로(주 1회 정도) 갱신해 주세요.

목표가는 전고점 회복가로 자동 계산됩니다.
회복 시 기대수익률 = (전고점 ÷ 현재가 − 1) × 100 이고, 이를 현재가에 반영한 값이 곧 전고점입니다. [📡 시세 갱신]을 누르면 현재가와 함께 목표가도 자동으로 다시 계산되고, [🎯 목표가·R 재계산] 버튼으로 따로 돌릴 수도 있습니다. 목표가를 직접 관리하고 싶은 종목은 [수정]에서 값을 넣으면 됩니다.

5 예산배분 탭 — "이번 달 80만원으로 뭘 몇 주?"

  • STEP 1 성향(공격형/표준형/안정형)을 고르면 대구분 목표비중이 채워집니다. 직접 수정도 가능하고, 합계가 100%가 아니면 경고가 뜹니다.
  • STEP 2 이번에 넣을 금액과 환율을 입력합니다. 대구분별 배정액이 즉시 계산됩니다.
  • STEP 3 각 대구분 안에서 종목별 비중을 정합니다. 대구분마다 방식을 따로 고를 수 있습니다.
    • 수동 입력 — 예전처럼 비중을 직접 넣습니다.
    • 고정비율 잠금 🔒 — 안전자산 35/35/30 처럼 한 번 정하면 계속 쓰는 조합에 씁니다.
    • 자동 (MDD 가중) — 김동면 방식. 진입강도 R ≥ 1.00인 종목만 골라 R에 비례해 비중을 자동 배분합니다. 신호가 하나도 없으면 R 상위 3종목에 배분합니다. 종목이 20개여도 비중을 손으로 넣을 필요가 없습니다.
    [📥 선택한 대구분의 관심주 일괄 불러오기]로 관심주를 통째로 계획에 넣고, [🔄 관심주 현재가 반영]으로 가격만 갱신합니다.
  • STEP 4 예산 × 대구분비중 × 종목비중 ÷ 1주 단가로 매수 가능 수량이 나오고, 남은 금액은 잔액 스윕이 R 높은 종목부터 1주씩 자동으로 채웁니다. 대구분 칩을 누르면 해당 대구분만 보이고 소계가 나옵니다. 1주도 못 사는 종목은 부족 금액이 표시되며, [+1주]로 강제 편입할 수 있습니다. 끝내 남은 돈은 [잔액을 이월금으로 적립]으로 다음 회차 예산에 합산됩니다. [매수기록]을 누르면 거래 입력창에 수량·단가가 자동으로 채워집니다.
  • 소수점 매수를 켜면 외화(USD) 종목만 소수점으로 계산되고, 원화 종목(예적금·국내주식)은 1주 단위를 유지하며 소수점 불가로 표시됩니다. 수량 칸에는 0.4651주 / ≒ 94,829원 ($68.72)처럼 주수·원화·달러가 함께 나오므로, 증권사의 수량주문·금액주문 어느 쪽이든 그대로 옮겨 적으면 됩니다. 거래 기록의 수량은 소수점 6자리까지 입력할 수 있고, 정수가 아닌 수량은 목록에 소수점으로 표시됩니다.
  • 통화는 USD가 원본입니다. 시세 자동조회가 달러로 들어오기 때문입니다. 통화를 원화로 잘못 지정하면 1주 단가가 환율(1,380배)만큼 어긋나므로, 해당 행에 통화 확인 경고와 [USD로] 버튼이 뜹니다. STEP 3의 [💱 통화 점검]으로 한 번에 정정할 수도 있고, [🔄 관심주 현재가 반영]은 가격과 함께 통화도 맞춰 줍니다.
  • 표가 넓어 불편할 때 STEP 4 헤더의 [⚙ 표시 항목]을 눌러 보고 싶은 열만 남기십시오. 최소(8열) / 기본(11열) / 전체(15열) 프리셋이 있고, 칩을 눌러 개별로 켜고 끌 수도 있습니다. 선택은 저장되며, 종목명·매수 가능 수량·관리 세 열은 항상 남습니다. 관리 열은 표 오른쪽에 고정되어 있어 가로로 스크롤해도 [수정]·[삭제] 버튼이 늘 보입니다.
  • 종목당 상한 캡(기본 30%)은 한 종목이 대구분 예산의 30%를 넘지 못하게 합니다. 듀레이션 긴 채권 등에 쏠리는 것을 막기 위한 장치이며, 1주 가격이 캡을 넘는 경우에는 1주까지 허용해 소액 예산에서 체결이 막히지 않게 합니다.

6 거래 탭 — 실제로 사고판 기록

보유종목은 따로 입력하지 않습니다. 여기에 매수/매도를 기록하면 수량·평균단가·실현손익이 자동 계산됩니다. 거래를 수정·삭제하면 보유 현황도 즉시 다시 계산되니, 잘못 입력했으면 고치기만 하면 됩니다.

  • 총금액은 수량×단가로 자동 계산되지만, 체결 금액이 다르면 직접 고칠 수 있습니다.
  • 환율은 그날 적용된 환율을 넣습니다. 투자원금(원화)은 이 환율로 누적됩니다.
  • 매도 시 보유수량을 넘기면 저장되지 않습니다.

7 보유종목 · 리밸런싱 탭

  • 현재가·전고점은 표에서 바로 입력하면 즉시 저장됩니다. 시세 자동 연동은 없습니다.
  • 대구분도 드롭다운으로 지정합니다. 지정하지 않으면 '미분류'로 잡힙니다.
  • 목표비중은 전체 자산 대비 이 종목의 목표 %입니다(대구분 목표비중과는 별개).
  • 맨 아래 추가 투입 가능 금액을 넣으면, 목표비중에 미달한 종목부터 채우는 방식으로 종목별 추가매수 금액이 계산됩니다.
  • 헤더를 클릭하면 대구분 묶음이 풀리고 정렬 모드로 바뀝니다. [대구분 묶어보기]로 되돌립니다.

8 계산기 탭

배당 재투자 시 눈덩이가 얼마나 커지는지 보는 시뮬레이터입니다. 배당성장률은 배당수익률이 매년 몇 %씩 오르는지, 주가상승률은 선택 항목(0이면 원금+배당만 반영)입니다.

9 월간리뷰 탭 — CPI는 여기에 넣습니다

CPI 전년비 상승률은 통계청이 매달 초 발표하는 소비자물가지수의 전년 동월 대비 상승률(%)입니다.
예: 2026년 9월 소비자물가가 작년 9월보다 2.1% 올랐다면 → 월 선택 2026-09, CPI 칸에 2.1 입력.
확인처: 통계청 KOSIS 또는 한국은행 경제통계시스템의 '소비자물가지수 등락률(전년동월비)'. 미국 자산 위주라면 미국 CPI YoY를 넣어도 됩니다 — 중요한 건 기준을 한 가지로 계속 유지하는 것입니다.
  • 월 수익률 — 그 달 내 계좌가 몇 % 늘었는지. 물가보다 높으면 물가 상회, 낮으면 물가 하회로 자동 판정됩니다.
  • 수령 배당금 — 그 달 실제로 들어온 배당·분배금(원). 이 돈은 1단계 현금자산에 모았다가 재투자합니다.
  • 기록이 쌓이면 상단에 단순 누적수익률과 연환산 수익률(CAGR)이 계산되고, 홈의 월별 추이 그래프에 CPI와 함께 그려집니다.

10 데이터 저장 · 백업

기본적으로 모든 데이터는 이 브라우저에만 저장됩니다(localStorage). 서버로 전송되지 않는 대신, 브라우저 데이터를 지우거나 다른 PC에서 열면 내용이 없습니다. [JSON 백업]으로 주기적으로 파일을 받아두세요. 다른 PC에서는 [JSON 복원]으로 그대로 이어서 쓸 수 있습니다. [엑셀 다운로드]는 보유종목·거래내역·월별리뷰·예산배분계획·관심주 5개 시트로 받습니다.

11 ☁ 여러 기기 동기화 (선택 사항)

헤더의 ☁ 동기화 표시를 누르면 본인 소유의 Firebase 프로젝트에 연결해, PC·휴대폰 등 여러 기기에서 같은 데이터를 실시간으로 볼 수 있습니다. 연결하지 않아도 앱은 지금처럼 정상 작동합니다.

  • Firebase 콘솔에서 무료 프로젝트를 만들고 Firestore와 이메일/비밀번호 로그인을 켠 뒤, 발급되는 firebaseConfig를 동기화 창 1단계에 붙여넣습니다. (자세한 절차는 동기화 창 안에 그대로 안내되어 있습니다.)
  • 이메일·비밀번호로 같은 계정을 다른 기기에서도 로그인하면 그 순간부터 실시간으로 데이터가 맞춰집니다.
  • 동기화 창에 있는 보안 규칙을 그대로 붙여넣으면 본인 계정으로 로그인한 사람만 자기 데이터를 읽고 쓸 수 있어, 이 코드가 공개 GitHub 저장소에 올라가 있어도 안전합니다.
  • 두 기기에서 동시에 각각 값을 고치면 나중에 저장된 내용이 이전 내용을 덮어씁니다(자동 병합 없음). 동시 편집은 피하는 것이 안전합니다.
  • 연결을 끊고 싶으면 동기화 창에서 [연결 해제]를 누르면 되고, 이후에는 다시 이 브라우저의 localStorage만 사용합니다.
